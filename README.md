# Smart Resume

A Java library that parses resumes (Markdown, PDF, XML) and converts them into vector embeddings for LLM response templates.

## Features

- 📄 Multi-format support: Markdown, PDF, XML
- 🔢 Convert resume content to vector data
- 🤖 Language model integration interface

## Requirements

- JDK 21+
- Gradle 8+

## Installation

```gradle
dependencies {
    implementation 'com.github.ehsun2000:smart-resume:0.1.0'
}
```
